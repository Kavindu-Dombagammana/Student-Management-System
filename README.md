# Student-Management-System

A simple **Student Management System built using Java**. This project is a beginner-friendly console application created to practice fundamental Java programming concepts and basic data management.

## 📌 About the Project

The system allows users to manage student information through a simple console-based interface. It does not use a database or Object-Oriented Programming (OOP). Instead, student data is temporarily stored using **arrays**.

## ✨ Features

* Add student details
* View all students
* Search for a student
* Update student information
* Delete student records
* Store data using arrays
* Simple console-based interface

## 🛠️ Technologies Used

* **Java**
* Java Arrays
* Variables and Data Types
* `if` / `else` statements
* `switch` statements
* Loops
* Methods
* User input using `Scanner`

## 💾 Data Storage

This project **does not use a database**.

All student information is stored temporarily in **Java arrays** while the program is running.

Because the data is not saved to a database or file, **all student records will be lost when the program is closed**.

## 🎯 Project Purpose

The main purpose of this project is to practice the fundamentals of Java programming, including:

* Arrays
* Loops
* Conditional statements
* Methods
* User input
* Basic CRUD operations
* Menu-driven programs

## 📚 Project Level

**Beginner Java Project**

This project was created as a learning exercise to strengthen fundamental Java programming skills and understand how a basic management system works.
